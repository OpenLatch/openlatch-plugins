# Security Policy

## Reporting a Vulnerability

Report vulnerabilities privately; do not open a public issue or pull request.

- Use GitHub's **private vulnerability reporting** on this repository (Security tab, "Report a vulnerability"), or
- write to **security@openlatch.ai**.

Include a description of the issue and the steps to reproduce it. We acknowledge a report within 2 business days and tell you when it is resolved.

## Scope

This repository holds generated copies of the OpenLatch plugin and its marketplace manifests. Every change reaches it through a reviewed pull request that passes the `validate` and `sync-guard` checks. A report about the OpenLatch platform itself goes to the same address.
